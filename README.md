I study **political bias and fairness in web information systems**. My work measures how bias appears in search engines, web corpora, and large language models (LLMs), and builds methods that reduce it in retrieval-augmented generation (RAG).

## 🔍 Research Interests

- **Bias in search engines**: personalization, filter bubbles, and information disparities across users
- **Bias in web corpora and LLMs**: how political bias in training data carries over to models
- **Fair retrieval and RAG**: mitigating political bias in retrieval-augmented generation
- **Large-scale data pipelines**: web and social media data collection, distributed graph representation learning
